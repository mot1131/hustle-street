# Hustle Street

A 2–5 player phone board game: buy Adelaide suburbs, pick a career, get married, have kids, trade with your mates and retire rich.

**Play:** https://mot1131.github.io/hustle-street/ — tap **Host a new game**, then **Invite** to send your mates the link. They open it in Safari or Chrome. No app or account needed.

- The game runs on the host's phone and is saved there, so keep that screen on. If the host closes the page, reopen it and tap **Resume room**.
- Phones connect directly to each other (WebRTC via PeerJS). It works best on the same Wi‑Fi; some mobile networks block direct connections.
- Playing on one phone? Host, then add everyone's names on that phone.
- Sound effects are synthesised in the browser (Web Audio). Tap the speaker to mute.

Files: `index.html` (the whole game), `peerjs.min.js` (PeerJS 1.5.4, MIT), `fonts/` (Lilita One, Nunito, Barlow Condensed; SIL Open Font License, via Fontsource).
