# Hustle Street

A 2–4 player phone board game: buy Adelaide suburbs, pick a career, get married, have kids, trade with your mates and retire rich.

**Play:** open the GitHub Pages link on your phone, tap **Host a new game**, and share the room code or invite link. Everyone else opens the link in Safari or Chrome. No app or account needed.

- The game runs on the host's phone and is saved there, so keep that screen on. If the host closes the page, reopen it and tap **Resume room**.
- Phones connect directly to each other (WebRTC via PeerJS). It works best when everyone's on the same Wi‑Fi; some mobile networks can block direct connections.
- Playing on one phone? Host, then add everyone's names on that phone.

Everything is in `index.html`; `peerjs.min.js` is PeerJS 1.5.4 (MIT).
